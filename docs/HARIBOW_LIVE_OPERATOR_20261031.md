# HARIBOW LIVE 当日操作カード

修正版はまだ本番未反映です。下記の「音声再開」「再接続」は修正版にある操作です。実機確認と個別承認が終わるまで、本番GOにはしません。

## 配信前（運営）

- HARIBOW本人のiPhoneと、別回線の視聴端末を準備。視聴側はイヤホンを使う。
- iPhoneは給電し、画面ロックを避ける。電話・別アプリへの切替はカメラ/マイク停止につながる。
- YouTubeを予備にする場合、あらかじめLIVE可能なチャンネル・配信動画URL・公開/限定公開・埋め込み許可を確認する。URL未準備のYouTubeは予備として保証できない。

## HARIBOWがDIRECTを始める

1. SafariでHAKUに本人ログイン → LIVE管理 → HAKU DIRECT。
2. タイトルを入力 →「カメラ・マイクを準備する」。両方の許可を押す。
3. 映像の向き、前後カメラ、マイクONを確認 →「LIVE配信を開始」。準備だけではファンへ公開されない。
4. 運営の別端末で動く映像と声/演奏音を確認する。配信側のプレビューが映るだけでは成功としない。

「別の画面で準備中/配信中」と出たら、二重に開始しない。元の配信画面で終了する。準備だけで画面を閉じ、元画面が戻らない場合は約90秒後に準備を再試行する。元画面が戻らない場合は、本人のLIVE管理で現在の配信を終了してから開始し直す。通信断後の期限切れは再接続で新しい配信枠を取り直す。

## YouTube LIVEをHAKUへ連携する

1. YouTubeアプリ/StudioでLIVEを用意し、配信動画の「共有URL」をコピー。チャンネルURLやストリームキーは使わない。
2. DIRECT配信中なら、まずDIRECTを終了する。両方ONではDIRECTが優先される。
3. HAKUのLIVE管理 → YouTube LIVE連携 → URLを貼る → プレビュー →「HAKUで公開する」。
4. 別端末で再生と音を確認。非公開・埋め込み不可・チャンネルの配信制限はHAKUから解除できない。

これは「YouTubeで配信した映像をHAKU内で視聴する」機能。DIRECTの映像をYouTubeへ同時配信する機能ではない。

## ファンが見る・フォローする・応援する

- HARIBOWプロフィールを開き、LIVEを押す。
- DIRECTで無音なら「タップしてLIVE音声を再生」。YouTubeは公式プレーヤー内の再生・音量ボタンを押す。
- フォローはDIRECTの右側操作欄、YouTubeはプレーヤー下の「フォロー」。未ログインならログインする。
- 「応援」→ 金額選択 → Stripe Checkoutへ。DIRECTは応援画面に移動すると視聴が一度止まり、戻ると再接続する。
- 決済結果が不明なら連打せず、履歴・表示を確認。運営の確認作業で本番の実決済・返金・送金はしない。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 映像がない | 配信側のカメラONと許可、通信を確認。視聴側はLIVEを開き直す。プレビューだけで公開前ではないか確認する |
| 音がない | 配信側のマイクON、視聴端末の音量・出力先を確認。DIRECTは音声再開、YouTubeは公式プレーヤーの音声を操作 |
| 接続が切れた | 回線を戻して「再接続」。二重タブで開始しない。配信側と視聴側の両方で復帰を確認 |
| 別アプリ/画面ロック後に無音・黒画面 | プライバシー保護でカメラ/マイクが止まる。Safariへ戻り、必要なものだけ再開。長い中断後は一度終了して開始し直す |
| YouTubeを埋め込めない | 「YouTubeで開く」を押す。YouTubeは別タブで開き、HAKUのタブは残る。HAKUへ戻ってフォロー・応援できる |
| DIRECTが復旧しない | DIRECTを終了 → 用意済みのYouTube LIVE URLをHAKUへ登録して公開。別端末で再確認する |

## 終了

- DIRECT：「LIVE終了」→ 確認。別端末のLIVE表示が終わることを確認。エラーなら回線を戻して終了を再試行する。
- YouTube：**YouTube側で配信終了し、HAKU側でも公開をOFF**にする。HAKUのOFFだけではYouTubeは終わらない。終了後も録画が残る場合がある。
- 端末が落ちた場合、配信中LIVEの終了にはSFU接続を確認するwatchdogが必要。SQLの定期処理だけで終了するとは限らない。監視が未稼働なら運営者が終了を確認する。
