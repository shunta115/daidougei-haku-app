# HAKU 新規パフォーマー登録ガイド

## 1. HAKUへ無料登録

スマートフォンで「パフォーマー登録」を開き、次の3項目だけ入力します。

1. 芸名
2. メールアドレス
3. パスワード

確認メールが届いたら、メール内のリンクを開いてログインしてください。Stripeの設定は後から行えます。HAKU登録だけで決済や送金が実行されることはありません。

## 2. 公開プロフィールを入力

ジャンル、自己紹介、活動地域、プロフィール写真を入力して保存します。途中の入力内容は同じ端末に一時保存されます。本名や本人確認書類、銀行口座は公開プロフィールには入力しません。

## 3. Stripeの受取設定

登録状況画面で「受取口座を設定する」を1回押します。以後はStripeの画面で案内に従います。

- 本名・生年月日・住所などの本人確認情報
- 顔写真付き本人確認書類など、Stripeが指定する書類
- 売上の振込先銀行口座
- メール認証または2段階認証

必要な項目は個人・法人、審査状況などで異なります。Stripeが求める本人確認やセキュリティ確認は省略できません。

## 中断・リンク期限切れ・認証後の戻り方

- 中断した場合はHAKUへログインし直し、「Stripeで設定を続ける」を押します。既存アカウントの続きが開きます。
- リンクが期限切れになった場合は、HAKUが同じアカウント用の新しいリンクを発行します。新規アカウントを作り直す必要はありません。
- StripeからHAKUへ戻っただけでは完了扱いになりません。HAKUがStripeの最新状態を再確認します。
- 「審査中」は提出済み情報をStripeが確認している状態です。「利用制限」とは別です。
- 「受取設定完了」はHAKUからStripeアカウントへ送金できる状態を示します。銀行への入金完了を意味しません。

## 困ったとき

- 通信エラー: 回線を確認して「状態を更新」を押します。
- 未提出情報: 「Stripeで設定を続ける」を押し、Stripeに表示される項目を入力します。
- 審査中: 同じ情報を繰り返し送らず、Stripeから追加依頼が来た場合だけ対応します。
- アカウント確認エラー: 売上・送金履歴保護のためHAKUは自動で別アカウントへ置き換えません。HAKU運営へ連絡してください。

本人確認書類や銀行口座情報をHAKUの問い合わせ欄へ送らないでください。これらはStripeの安全な画面だけで入力してください。
