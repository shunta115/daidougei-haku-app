# 物理iPhoneで必要な最終受入（目安10〜15分）

対象はPR #101の保護付きPreviewとTEST Supabase `aeqskxxykzapgaudbeqa`のみ。本番アカウント・本番予定を使わない。パスワードやトークンは証跡に写さない。削除・送金・返金・実配信を行わない。

## 準備

- iPhoneの機種、iOS/Safariのバージョン、実施時刻（JST）を記録する。
- TEST専用の承認済み出演者アカウントで通常ログインする。通知を見る場合はTESTファンアカウントも必要。
- Preview保護の認証とHAKUのTESTログインは別。URLの環境名だけでTESTと判断せず、検証者が接続先を確認する。
- 予定タイトルは `QA PR101 iPhone <実施時刻>`。公開座標はテスト用の公開地点を使用し、個人の現在地を予定へ登録しない。
- アプリ内Google Mapsは、既存のTEST用キーとreferrer制限・0円枠が確認できた場合だけ実施。本番キーをコピーしない。未確認なら外部地図だけを確認し、アプリ内地図欄は「未実施」とする。

## 実機でしか確定できない項目

| 操作 | 合格条件 | 証跡 |
|---|---|---|
| QRをPNG保存 | 写真/ファイルの実際の保存先で画像を開ける。拡大してQRを読み取れる | 保存先の画像、読取先の公開プロフィールURL（認証値は含めない） |
| QRを印刷 | 印刷プレビューがA4の1ページで切れない。まず「ファイルに保存」で確認する | PDFまたはプレビュー。紙への実印刷は任意 |
| iPhone共有シート | Safariの共有シートが開き、正しい予定URLをコピー/「ファイル」等へ渡せる | シートとコピーしたURL。宛先・連絡先は写さない |
| LINE/X | 正しい予定の公開URL・タイトルが作成画面へ渡る。送信/投稿せずキャンセルする | 作成画面のURL/文面だけ |
| QRカメラ読取 | 保存/印刷したQRを別の端末で読み取り、公開プロフィールへ着地する | 読取結果。端末のログイン状態や秘密情報は写さない |
| GPS許可 | Safariの位置情報許可で距離表示が出る。測位しない端末で「位置確認中」に固まらない | 距離の表示。個人の正確な位置は保存しない |
| GPS拒否 | 位置情報を拒否しても予定閲覧、地域・会場検索、外部地図リンクが利用できる | 拒否後の検索画面 |
| Safariをバックグラウンドへ移動して復帰 | 予定変更・非公開・中止後に、復帰または20秒以内の再取得で最新化される | 復帰前後の画面と時刻 |

## TEST実接続の操作順

1. 通常ログイン→タイトル・日付・開始/終了・Asia/Tokyo・公開会場名・確認済み座標を入力→公開。
2. 予定一覧で同じID/タイトル/時刻を確認。MAPで同じ会場を確認。共有リンクを未ログインのプライベートタブで開く。
3. 端末で「現在より5分後〜10分後」の予定を作り、開始前/開始後/終了後を確認。終了未登録は実演中扱いにしない。実際のLIVE配信を開始しない。
4. 時間変更→一覧・MAP・共有先が更新されることを確認。延期・中止は一覧に状態を残してMAPから除外。非公開は匿名の一覧・共有先に公開されないことを確認。
5. 複製と複数日登録を行い、登録数・日付・会場を確認。入力エラー時に勝手な日付省略や重複登録がないことを確認。
6. TESTファンがフォローし、当日予定の通知画面を2回開く。同じ当日通知が増殖しない。設定OFFの対象に通知を作らない。#91はHAKU内通知であり、未起動端末への定時Pushではない。
7. 終了後のQA予定は削除しない。TEST内で非公開またはアーカイブにして、作成したIDを検証記録へ残す。
