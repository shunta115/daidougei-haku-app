## ファン向け X

好きなパフォーマーの「今」をHAKUで。フォローして、公開LIVEや出演予定をチェック！
LIVE通知を受け取りたい方は、HAKUの通知画面からご自身でONにできます。
iPhoneはSafariからホーム画面に追加し、HAKUを起動して設定してください。
応援は視聴画面から、好きなタイミングで。
https://daidougei-haku-app.vercel.app/live

## ストーリーズ 3枚

1. 会場に行けない日も、HAKU LIVEでパフォーマンスを楽しもう。
2. 好きなパフォーマーをフォロー → 通知画面でLIVE通知をON。
3. iPhoneはホーム画面に追加してから設定。視聴・応援はこちら［HAKUリンク］。

独自の文字・図形だけで構成し、公式Instagramの画像・映像は転載しない。

## リール台本 15秒

0–4秒：HAKUの公開LIVE画面を、撮影許諾済みのデモ素材で紹介。
4–8秒：「フォローしてLIVEを見逃さない」。通知同意は任意であることを表示。
8–12秒：ホーム画面追加→通知設定の独自ガイド。
12–15秒：HAKUリンクと「応援もここから」。実在しない視聴者・応援人数は表示しない。

## パフォーマー向け案内

1. 出演予定を登録し、公開プロフィールのリンクをSNSで共有。
2. LIVE前に本人のみの非公開テストで画角・音声を確認。
3. 公開時は「通知なし」または「フォロワー通知あり」を自分で選択。
4. 通知ありでも、継続した公開LIVEと受信者の明示同意を確認してから配信。
5. 応援は既存のHAKU導線を利用。通知から決済を自動実行しない。
