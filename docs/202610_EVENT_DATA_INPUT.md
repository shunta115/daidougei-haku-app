# 大道芸博 2026 本番データ入力仕様

対象日は2026年10月10日から12日です。Production投入には
`supabase/seed_202610_event_template.sql`を使用し、初回は必ず末尾を`rollback`のまま実行します。

## データ対応

| 情報 | 保存先 | 必須項目 |
| --- | --- | --- |
| イベント | `events` | 日英名称、表示日程、開催地、開催時間、開始日、終了日、公開状態 |
| 会場・エリア | `event_venues` | 一意ID、日英名称、説明、緯度、経度、表示順 |
| 出演者 | `event_lineup` | 承認済みパフォーマーの登録メール、表示順 |
| 通常出演 | `event_slots` | 出演者、日付、開始・終了、会場、1から3の回番号、LIVE予定 |
| 特別ステージ | `event_slots` | 10月12日、16:00から17:00、順位1から3、会場 |
| 人気投票 | `event_votes` | ログイン済みfanにつきイベントごとに1票 |
| ランキング | 投票の集計 | `event_votes`を件数順に集計。特別ステージ割当は別途確認後に実行 |
| LIVE | `live_sessions.event_slot_id` | 開始時刻に該当する出演枠へ自動紐付け |

## 運営から必要な入力

1. 3日間それぞれの開場・終了時刻
2. 全会場・エリアの正式名称、短い説明、緯度経度、表示順
3. 出演者全員の登録メールアドレスと表示順
4. 出演者ごとの出演日（1日）
5. 各出演者の通常公演3回分の開始・終了時刻と会場
6. 各通常公演をLIVE配信するか
7. 特別ステージの会場名と、20分ずつ3組でよいか
8. 人気投票の開始・終了日時、同票時の決定方法、結果公開時刻
9. 上位3組確定・特別ステージ反映を行う責任者
10. 雨天時の会場・時間変更ルールと公式案内文

## 安全な投入手順

1. 全パフォーマーが登録・受取設定・運営承認を完了する。
2. seed内のTODOと例示メールをすべて実値へ置換する。
3. `rollback`のまま実行し、events、venues、lineup、slotsのsummaryを確認する。
4. 3回公演と16:00から17:00の特別枠を運営表と照合する。
5. 承認後だけ末尾を`commit`に変更して適用する。
6. 投票締切後、`assign_202610_finalists_template.sql`を`rollback`のまま実行する。
7. 上位3組と順番を人間が確認してから特別枠を確定する。
